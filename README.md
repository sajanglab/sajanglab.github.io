# 사장랩 — 자영업자 무료배포용 견적서 앱

회원가입·설치·결제 없이 쓰는 **무료 견적서 · 거래명세서 · 공사내역서**와 **부가세 계산기**,
**마진율 계산기**, **3.3% 인건비 계산기** 웹앱입니다.
앱을 열면 작성폼이 아니라 **홈 메뉴판**(8개 메뉴 타일 + 하단 탭 바)이 먼저 뜨고,
`index.html` 하나로 동작하며(외부 의존은 Pretendard 폰트 CDN 1개), 입력값은 전부 브라우저
`localStorage`에만 저장되며 서버로 전송되지 않습니다.

> 이 폴더는 **공개 배포용**입니다. 실제 사업자·개인 정보는 한 글자도 들어 있지 않고,
> 처음 열면 사업자 칸이 비어 있으며 사용자가 [내 사업자 저장]으로 직접 입력합니다.

## 폴더 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체(단일 파일). 홈 메뉴판·하단 탭·3종 문서·계산기 3종·A4 캔버스 렌더·PNG/PDF·메일 |
| `privacy.html` | 개인정보처리방침 — 애드센스·구글플레이 심사 필수 페이지 |
| `manifest.webmanifest` | PWA 매니페스트 (이름·색·아이콘·바로가기) |
| `sw.js` | 서비스워커 — 오프라인에서도 열리는 앱 껍데기 캐시 (`sajanglab-v3`) |
| `icons/icon-512.png` · `icons/icon-192.png` · `icons/icon-180.png` · `icons/apple-touch-icon.png` | 앱 아이콘 — 병아리 마스코트(딥네이비 풀블리드) |
| `icons/favicon-32.png` · `icons/mascot-64.png` · `icons/mascot-128.png` · `icons/mascot-192.png` | 파비콘·앱바 36px 뱃지용 마스코트(얼굴 크롭) |
| `icons/og-1200x630.png` | 공유 카드 이미지(og:image / twitter:image) |
| `robots.txt` | 검색·애드센스 크롤러 허용 |

이 폴더에는 배포에 올릴 파일만 들어 있습니다. 아이콘·공유 이미지는 `icons/` 폴더에 있습니다. 브랜드명을 바꾸려면 `index.html`의
`<title>`·`meta`·`.appbar h1`·`.site-foot`·`privacy.html`·`manifest.webmanifest`의 이름과
`const BRAND`(스크립트 상단)를 바꾸면 됩니다.

## 기능

- **홈 메뉴판**: 앱을 열면 바로 메뉴판. 상단에 지금 쓰는 **내 사업자 요약**(미등록이면 `내 사업자 정보 먼저 저장해 보세요` 원클릭 버튼),
  가운데 **우리 사장님 메뉴 8개 타일**(견적서 · 거래명세서 · 공사내역서 · 부가세(VAT) · 마진율 · 3.3% 인건비 · 내 사업자 · 문서함),
  아래에 소개글·자영업자 FAQ·개인정보처리방침 링크. 타일 8개 모두 바로 동작합니다(3종 문서는 그 양식으로 작성 화면 열기, 나머지는 해당 모달).
- **하단 탭 바**(모바일): `홈` · `문서작성` · `부가세·계산` · `문서함` 고정. 작성 화면으로 들어가면 탭 바 대신 기존 액션 바
  (`합계금액 + 메일/PNG/PDF/저장`)로 자동 전환되고, 상단에 `← 홈으로` 버튼이 생깁니다.
- **문서 3종**: 견적서 · 거래명세서 · 공사내역서 — 입력값 100% 공유, 탭만 바꾸면 양식이 바뀜
- **부가세(VAT) 계산기**: 홈 타일 · 탭 `부가세·계산` · 작성 화면 앱바 **[% 부가세]** 세 곳에서 열림 —
  - 공급가액 → 합계: 공급가액에 10%를 더한 세액·합계
  - 합계 → 공급가액: `공급가액 = round(합계 / 1.1)`, `세액 = 합계 − 공급가액` (예: 1,100,000 → 1,000,000 / 100,000)
  - 빠른 금액 `+1만`·`+10만`·`+100만`·`초기화`, 결과 복사, 계산한 공급가액을 품목 단가에 바로 넣기(기존 단가가 있으면 확인 후 교체)
  - 드롭다운 위 **`들어갈 품목 선택`** 라벨로 어느 품목 단가에 넣는지 바로 보임
- **마진율 계산기**: 판매가 · 매입원가 · 플랫폼/카드 수수료% · 배송·기타비 → **순이익 · 마진율% · 원가율% · 손익분기 판매가** 즉시 계산,
  판매가 빠른 금액(`+1만`·`+10만`·`+100만`)·초기화·결과 복사 (예: 30,000 / 15,000 / 3.3% / 2,500 → 순이익 11,510원 · 마진율 38.4% · 손익분기 18,098원)
- **3.3% 인건비 계산기**: `세전 → 실수령`(소득세 3% + 지방세 0.3% = 3.3%)과 `실수령 → 세전` 역산 2모드,
  빠른 금액·결과 복사 (예: 1,000,000 → 실수령 967,000 · 소득세 30,000 · 지방세 3,000)
- **부가세 3모드**(문서): 포함 / 별도 / 일반·면세 (문서에도 표기, 합계 한글 병기)
- **사업자 여러 개**: 상호·사업자등록증 상호·대표·사업자번호·업태·종목·연락처·공사내역서 연락처·주소·이메일·계좌·도장을 사업자별로 저장
- **도장**: 이미지 업로드 → 그 사업자 문서에 자동 날인(견적서·거래명세서는 서명란, 공사내역서는 공급자 표 대표자 자리)
- **내보내기**: A4 3배 해상도 PNG(2382×3369, 여러 장은 세로로 이어 붙임), PDF·인쇄(`@media print`)
- **메일**: 거래처 이메일을 적고 [메일] → `mailto:`로 제목·본문(문서번호·합계·계좌·연락처) 자동 작성
- **기록함**: 저장/불러오기/복제/삭제/검색, 견적서 → 거래명세서 1클릭 전환, 전체 JSON 백업·복원
- **예시 채우기(테스트용)**: 가상의 값(예시상사·홍길동 등)으로 사용법을 먼저 확인
- **PWA**: 아이폰 사파리 공유 → 홈 화면에 추가, 안드로이드 크롬 설치 배너, 오프라인 실행

## 개인정보처리방침 (`privacy.html`)

애드센스·구글플레이 심사에 필요한 페이지입니다. 상단 헤더·본문·푸터 모두 `index.html`과 같은 톤이고,
`index.html` 푸터의 **개인정보처리방침** 링크로 연결됩니다. 서비스워커 캐시에도 들어 있어 오프라인에서도 열립니다.

- `robots: index, follow` + 설명·canonical
- 회원가입·로그인·서버 저장이 없다는 점, 입력값은 기기 `localStorage`에만 남는다는 점
- Google AdSense 쿠키·맞춤형 광고 안내, `https://adssettings.google.com/` 수신거부 링크,
  구글 파트너 사이트 데이터 안내·aboutads.info 링크
- 글꼴 CDN·광고 요청 시 IP 등 기술 정보가 전달될 수 있다는 안내
- 보관·삭제 방법(앱의 [저장된 모든 데이터 지우기], 브라우저 사이트 데이터 삭제)
- 문의처: **개인 메일·휴대폰·실명·주소를 넣지 않고** "공개용 문의 메일 주소는 서비스 공개와 함께 안내" 문구로 두었습니다.
  메일이 정해지면 `privacy.html`의 9번 문단(그 자리에 HTML 주석 표시)을 실제 주소로 바꾸면 됩니다.

## 광고(애드센스) 넣는 곳

`index.html` 안에 상단·하단 두 곳의 슬롯이 준비되어 있습니다.

1. `<head>`에 애드센스 스크립트를 넣고 `ca-pub-XXXXXXXXXXXXXXX`를 발급받은 퍼블리셔 ID로 교체
2. `id="adTop"`(상단) / `id="adBottom"`(하단)의 `<ins class="adsbygoogle">`에
   실제 `data-ad-client`·`data-ad-slot` 값 입력
3. 스크립트의 `const ADS_ENABLED = false;` → `true`

승인 전에는 두 슬롯 모두 `display:none`이라 빈 광고 박스가 보이지 않습니다.
광고를 넣으려면 개인정보처리방침·쿠키 고지 페이지를 함께 두는 것이 안전합니다(애드센스 정책) — 이 폴더에는 `privacy.html`이 포함되어 있습니다.

## 배포 방법 (새 브랜드·새 깃허브 조직으로)

1. 깃허브에 새 조직/저장소(예: `내브랜드/내브랜드.github.io`)를 만들고 이 폴더의 파일을 올립니다.
2. 저장소 Settings → Pages → Branch `main` / root 로 설정. 주소는 `https://내브랜드.github.io/`.
3. (권장) 도메인을 붙이면 `CNAME` 파일을 추가합니다.
4. 배포 후 확인: `/index.html`, `/privacy.html`, `/manifest.webmanifest`, `/icons/icon-512.png`, `/icons/apple-touch-icon.png`, `/icons/og-1200x630.png`, `/sw.js` 모두 200.
5. `index.html`의 `<link rel="canonical" href="./">`는 도메인이 정해지면 절대 주소로 바꿔 주세요.

## 안드로이드 앱(.aab)으로 낼 때

PWA 구성(manifest + service worker + 512 아이콘 + HTTPS)이 이미 갖춰져 있어 바로 TWA로 감쌀 수 있습니다.

- **PWABuilder**: https://www.pwabuilder.com 에 배포 주소를 넣고 Android 패키지 생성 → `.aab` 다운로드
- 또는 **Bubblewrap**:
  ```bash
  npm i -g @bubblewrap/cli
  bubblewrap init --manifest https://내주소/manifest.webmanifest
  bubblewrap build
  ```
- 스토어 등록 시 `assetlinks.json`(`/.well-known/assetlinks.json`)을 배포 폴더에 올려야 주소창 없는 앱으로 뜹니다.
- 구글플레이 데이터 보안(Data safety) 신고에는 "앱이 수집하는 데이터 없음(모든 입력값은 기기 내 저장)"으로 적고,
  개인정보처리방침 URL에 배포 주소의 `/privacy.html`을 넣습니다.

## 알아둘 점

- 데이터는 브라우저 단위로 저장됩니다. 브라우저 저장공간을 지우면 사라지니 가끔 [전체 백업]으로 JSON을 받아 두세요.
- 인쇄는 여백 **없음**, 배율 **100%**가 가장 깔끔합니다.
- 폰트는 CDN에서 받아오므로 오프라인 첫 실행에서는 시스템 폰트로 표시될 수 있습니다(문서 출력에는 영향 없음).
